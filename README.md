# ReForm Pilates Studio — сайт

Одностраничный сайт студии пилатеса ReForm (Худжанд).
Сейчас опубликован по адресу: https://reform-pilates-studio.vercel.app

Это обычный статичный сайт: без сборки, без сервера и без зависимостей.

## Состав

| Файл / папка | Что это |
|---|---|
| `index.html` | Весь сайт: разметка, стили и скрипты в одном файле |
| `img/` | Фото студии (из Instagram @reform_pilates.studio), логотипы, иконка, картинка для превью ссылок (`og-image.jpg`) |
| `robots.txt`, `sitemap.xml` | Файлы для поисковиков |
| `google7964f15857f821e1.html` | Подтверждение сайта в Google Search Console (служебный) |
| `7da4f15e7b8e6e6081ba46ecb314c2fc.txt` | Ключ IndexNow для Яндекса и Bing (служебный) |

## Как открыть

Дважды кликните `index.html`, и сайт откроется в браузере.
Шрифты (Cormorant Garamond, Golos Text, Tenor Sans) загружаются из Google Fonts, поэтому нужен интернет.

## Как опубликовать

Подойдёт любой статический хостинг, папку нужно загрузить целиком:

- **Vercel:** в папке выполнить `npx vercel deploy --prod`
- **Netlify:** перетащить папку на https://app.netlify.com/drop
- **GitHub Pages** или обычный хостинг по FTP: загрузить все файлы в корень сайта

## Если сайт переезжает на свой домен

1. Замените `https://reform-pilates-studio.vercel.app/` на новый адрес в `index.html` (canonical, og:url, og:image, JSON-LD), а также в `sitemap.xml` и `robots.txt`.
2. Файлы `google7964f15857f821e1.html` и `7da4f15e7b8e6e6081ba46ecb314c2fc.txt` относятся к текущему адресу. На новом домене их можно удалить, а сайт заново добавить в Google Search Console и Яндекс Вебмастер со своего аккаунта.
